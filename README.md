# Digital-Tasbeeh---Muslim-App
Digital Tasbeeh counter with 5 pre-loaded Islamic prayers. Offline &amp; free.
🎉 Initial Release

✨ Features:
- Beautiful Islamic counter with haptic feedback
- 5 pre-loaded Tasbeehs (Subhan Allah, Alhamdulillah, etc.)
- Dark mode for night prayers
- Progress tracking
- Offline functionality
- Clean, minimalist design

Coming soon:
- Full analytics

- Prayer times
